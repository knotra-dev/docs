Start with the guided demo. It shows the process using sample results and does not call a real AI model.

## Try the demo

Open Knotra Desktop. If the app is not available on your computer, ask a teammate to help you open the development version.

1. Open **Pipelines**.
2. Choose **New pipeline**.
3. Choose **Guided demo**.
4. Select **Research brief**.
5. Choose **Run demo**.
6. Choose **Start demo** in the window that opens.

Leave the example unchanged for this first try. The demo shows progress, pauses for your review, and can produce a sample file.

In **Runs**, **Inbox**, and **Artifacts**, use the **Guided demo** tab to see the demo's work.

## Get ready for real work

Real workflows need a running **engine**: the service that performs the steps. Opening desktop does not start that service.

Ask the teammate who manages your setup for the engine address, any required access token, and the profile to use. A profile is the set of AI and tool settings prepared for a workflow.

Your teammate can follow [Technical setup](/docs/contributing).

## Connect the app

1. Open **Settings**.
2. Paste the supplied address into **Engine base URL**.
3. Choose **Save address**.
4. Enter the access token if your teammate supplied one.
5. Choose **Connect engine**.

Wait for **Connected**. You can then [review an announcement](/docs/guides/first-workflow).

Runs may use a paid model; the guided demo uses sample data.
